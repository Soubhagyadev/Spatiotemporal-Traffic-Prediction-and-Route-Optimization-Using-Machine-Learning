## 2. Cleaning rules and their effect

| Rule | Records removed | Share of raw records |
|---|---|---|
| `missing_timestamp_or_link_id` | 0 | 0.000% |
| `non_numeric_speed` | 0 | 0.000% |
| `non_numeric_travel_time` | 0 | 0.000% |
| `non_nominal_status` | 4,055,012 | 33.610% |
| `speed_not_positive` | 0 | 0.000% |
| `travel_time_not_positive` | 0 | 0.000% |
| `duplicate_record` | 0 | 0.000% |
| `implied_length_outliers` (per segment, after cleaning) | 1,497 | 0.012% |
| **kept for hourly aggregation** | 8,009,907 | 66.39% |

Rules, in order of application:

1. `missing_timestamp_or_link_id` — unparsable `data_as_of` or `link_id`.
2. `non_numeric_speed`, `non_numeric_travel_time` — text that is not a number.
3. `non_nominal_status` — `status != 0`. The feed repeats the previous reading while a sensor is stale, and the flag is highly informative: 81% of `status = -101` rows repeat the preceding value of the same segment versus 6% of `status = 0` rows, and `-101` rows are ~10x over-represented among physically impossible readings.
4. `speed_not_positive`, `travel_time_not_positive` — sentinel zeros/negatives (a standstill would still report a positive travel time).
5. `duplicate_record` — repeated `(link_id, data_as_of)` inside a file; repeats across files are removed later, per segment, on the exact timestamp.
6. `implied_length_outliers` — `speed x travel_time` is nearly constant for a segment (median relative spread 2.4%), so readings deviating more than 30% from the segment's median implied length are measurement errors.

## 6. Known limitations

- The feed covers a fixed panel of road segments; links that were never observed cannot be predicted.
- `link_points` is truncated at 255 characters by the export, so segment geometry is recovered from the (untruncated) `encoded_poly_line` field where possible; the remaining segments fall back to a partial polyline.
- Sensor-implied segment length and polyline length disagree for some tunnels, bridges and ramp segments; this is reported rather than filtered, because the outlier rule compares each reading with the segment's own history.
- Congestion thresholds are absolute speeds, so a single threshold set is applied to both motorways and local streets.
